# Pond Crypto AI Agent

A small FastAPI agent intended as a starting point for Pond Protocol V1 integration.

## What it does

- `GET /manifest` describes the agent.
- `POST /runs` accepts a crypto question and asks an OpenAI model to answer it.
- `GET /tasks/{task_id}` is included for compatibility; the starter uses synchronous `200` responses.

## Deploy

1. Create an OpenAI API key.
2. Deploy this folder to a public HTTPS host such as Render.
3. Add these environment variables:
   - `OPENAI_API_KEY`
   - `POND_ACCESS_KEY` (the key generated by Pond)
   - `OPENAI_MODEL` (default: `gpt-5.6-luna`)
4. Test:
   - `https://YOUR-URL/`
   - `https://YOUR-URL/manifest`
5. Put the public base URL into Pond's **Agent URL** field.

## Important

Pond's screenshot indicates that its exact V1 request/response schema and access-key requirements are defined in its Integration Guide. This starter intentionally keeps the `/runs` parser flexible, but you should compare the returned JSON with Pond's current guide before publishing. If Pond specifies exact field names or a different authentication header, change those parts in `app.py`.
